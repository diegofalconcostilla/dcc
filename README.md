# DCC

A 2D dungeon crawler prototype drawing on the setting/tone of Matt Dinniman's *Dungeon Crawler Carl*: survivors ("crawlers") fight down through a multi-level "World Dungeon," broadcast as an intergalactic reality show.

Built in [Godot 4](https://godotengine.org/) (GDScript). Combat/movement is real-time and free-roam, Vampire Survivors-style: auto-attack the nearest enemy, dodge swarms, level up, survive the floor's clock.

The core experiment of this project is **LLM-generated content at runtime**: loot-box items and achievements are generated live by a local [Ollama](https://ollama.com/) model, not hand-authored, with a validation/clamping layer so generated loot stays balanced. See [`plan.md`](plan.md) for the full design notes and decision log.

## Current state (first playable slice)

- Free movement (WASD/arrows), auto-attack the nearest enemy in range
- `Tab` switches the active attacker between Carl and Donut (shared XP pool; the other does nothing while inactive)
- 10 sequential floors, 90 seconds each — clear a floor by surviving the timer, monster speed ramps up each floor
- XP pickups → level up → choose an upgrade
- Floor-end loot box and achievement check, generated by a local Ollama model with a local fallback if the model is slow/unavailable

## Running it

1. Install [Godot 4.7+](https://godotengine.org/download) (standard build, no Mono/.NET needed).
2. (Optional, for LLM-generated loot/achievements) Install [Ollama](https://ollama.com/download) and pull a model, e.g. `ollama pull llama3.2`. Without Ollama running, the game falls back to a local hand-written loot/achievement table automatically.
3. Open the project in Godot, or run it directly:
   ```
   godot --path .
   ```

For fast iteration on the loot/achievement flow, override the floor timer with an environment variable so floors clear in seconds instead of minutes:

```
# cmd.exe
set DCC_FLOOR_DURATION=3 && godot --path .

# PowerShell
$env:DCC_FLOOR_DURATION = "3"; godot --path .
```
